# KOLE Investment

A modern investment and insurance website built with HTML5, CSS3, and JavaScript.

## Features
- Responsive design
- Modern UI/UX
- Interactive components
- Insurance service showcase
- Contact forms
- Customer testimonials
- Blog section

## Getting Started
1. Clone the repository
2. Open `index.html` in your browser
3. For development, use a local server

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Google Fonts

## Structure
- `index.html` - Main page
- `styles.css` - Main stylesheet
- `script.js` - JavaScript functionality
- `images/` - Image assets
